運作原理

乾淨的架構，剛好的距離

最初想用 Accessibility 去驅動「真的 Finder」當抽屜，複雜度爆炸。最後換成自己的視窗——簡單非常多。

1

自己的視窗，不碰真 Finder

用自己的 NSPanel，一行 collectionBehavior 就出現在每個 Space——沒有 Apple Events、Accessibility 或私有 SPI。

2

從任一邊召喚

選單列或全域快捷鍵 ⌘` ／ ⌃⌥+方向鍵；滑鼠在哪個螢幕，就召喚到那個螢幕。

3

自動滑回邊外

點到別的 app 就自動 park 到螢幕外，再按一次滑回來。拖內側邊界調寬高，下次召喚記得。

功能

像 Finder，但隨叫隨到

用 NSOutlineView 做到很接近 Finder 列表檢視，再加上抽屜該有的順手。

🪟

Liquid Glass 外觀

macOS 26 半透明視窗，側欄與檔案列表做成兩張圓角內嵌卡片。

⭐

鏡像 Finder 最愛

原生 SwiftUI 側欄讀取 Finder 的共享清單，還能拖曳重新排序。

🗂️

真・Finder 列表

NSOutlineView 撐起多欄位、點標題排序、Group by Kind、空白鍵 Quick Look。

⌨️

全域快捷鍵

Carbon 註冊、不用多要權限；⌘` 召喚、⌃⌥+方向鍵指定邊。

🖥️

出現在每個 Space

一行 collectionBehavior，跨所有 Space 與全螢幕 app 都召喚得出來。

📐

記住你的尺寸

拖抽屜內側邊界調整寬高，下次召喚就是你上次的大小。

安裝

拖進「應用程式」就好

下載解壓、拖進去。自簽 App 第一次打開用右鍵 → 打開，或跑下面這行清掉 quarantine。

# 清除 quarantine 後直接打開
xattr -dr com.apple.quarantine /Applications/Findly.app
open /Applications/Findly.app

完整磁碟取用權限：抽屜要瀏覽整個檔案系統、側欄要鏡像 Finder 最愛，請到「系統設定 → 隱私權與安全性 → 完整磁碟取用權限」把 Findly 打開。沒授權的話，桌面／文件／下載／雲端等受保護資料夾會列成空的。

寫在最後

我想要一個「隨手叫出來、用完就消失」的檔案抽屜。試過去借真 Finder 的視窗，發現代價太大，最後決定自己刻一個——換來乾淨非常多的架構。

Findly 很小、開源、免費。整個專案是用 Claude Code 邊聊邊長出來的。如果它讓你拿檔案更順手，那就值得了。
